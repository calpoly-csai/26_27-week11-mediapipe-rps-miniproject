Hand photos for laptops without a webcam (8 included; add your own .jpg/.png too):

    python main.py --images sample_images

Each round uses the next photo.

hand1-8.png are from the Rock Paper Scissors dataset by Laurence Moroney
(https://laurencemoroney.com/datasets.html), CC BY 2.0. Names are neutral on
purpose: the move comes from hand detection, not the filename.
